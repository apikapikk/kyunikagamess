# Dokumentasi Kyunika Games

Kyunika Games adalah konsep game kuis berbasis web yang dimainkan terutama di mobile. Pemain membuat profil singkat, memilih karakter mini, lalu menjelajahi kota 3D untuk menemukan dan menjawab soal.

## Dokumen

- [Konsep game](./game-concept.md) — visi, core loop, alur pemain, dan rancangan fitur awal.
- [Kota prosedural](./procedural-city.md) — cara membuat kota terasa berbeda setiap sesi tanpa kehilangan kontrol desain.
- [Game world](./game-world.md) — kontrak game shell, seed kota, dan rencana renderer 3D.
- [Inventaris aset](./asset-inventory.md) — aset 3D yang tersedia dan rencana penggunaannya.
- [Development log](./development-log.md) — catatan keputusan dan progres pengembangan.
- [Admin dan room API](./admin-and-room.md) — rancangan bank soal, kode room, dan payload match.
- [Firebase setup](./firebase-setup.md) — cara mengisi environment Firebase dengan aman.
- [Development log](./log.md) — catatan kronologis setiap perubahan implementasi.
